# 裝置離線結帳

在要收銀的裝置、瀏覽器及原入口網址登入，按「下載離線資料」。完成後會顯示「離線資料已就緒」。下載包含商品／價格、進行中書展、已有交易，以及結帳、掃碼與收款碼所需程式。各教會登入資料與書房入口分開保存，密碼與 session token 不寫入裝置資料庫。

離線仍從原網址開啟，可進入已下載場次、掃碼、搜尋、保留草稿與記錄結帳。結帳先等 IndexedDB 交易提交成功，再清空購物車；不等待雲端 HTTP。未同步時顯示「本機待同步」，恢復連線並開著 POS 時自動補送，或按「重試同步」。裝置離線授權限最後一次成功驗證後 7 日；連線驗證會更新期限，伺服器明確拒絕授權時必須重新登入，待同步資料不會消失。

初次登入、建立新書展、更新商品／庫存與正式 PILOT 匯出需要連線。正式匯出會先確保所有本機待同步資料補送完成。離線採用最近下載的商品與價格；出貨流水號在雲端接受交易後取得，原始 transaction identity、日期、付款與商品金額原樣保留。

補送以前保存確切的請求與原 baseline。即使雲端成功但回應遺失，先重送相同請求，再補送後續修改，避免重複入帳與消除操作被舊回應還原。衝突不自動覆蓋：顯示雲端與裝置資料，由使用者逐項確認。可下載待同步備份。帳號登出會撤銷此入口的離線授權，保留待同步資料供重新登入後恢復。

清除網站資料、重設瀏覽器、無痕視窗關閉或換瀏覽器會失去該瀏覽器尚未補送的裝置資料。書展結束前確認「待同步」已清空。已補送交易仍由雲端持久保存。

Service Worker 僅控制 `/pos/`，不攔截電子報與其他網頁，API 也不經 HTTP 快取。部署產生包含本版 fingerprinted chunks、掃碼 worker/WASM、結帳 HTML 等完整資源的 manifest；資源不完整時不得標示準備完成。保留舊版 assets 供尚未關閉的收銀台使用，入口頁快取跨版本保存，下一次連線開啟時更新。

驗證：`node --test tests/*.test.mjs`。另以建置後 `tests/offline-browser.mjs` 搭配 Playwright 執行獨立 localhost fixture，測試桌機書房與手機教會的斷線、重新整理、連續結帳、兩秒伺服器延遲、補送、API 排除及 service worker 升級；不使用正式營運資料。
